# Souhail HOUSNI — Personal Portfolio

My personal portfolio site: industrial digitalization, AI & data science engineering.

Built with TypeScript and [Next.js](https://nextjs.org/) (static site generation), [Chakra UI](https://chakra-ui.com/) and [Framer Motion](https://www.framer.com/motion/) for animations.

## Editing content

- `config/sidebar.ts`: social links
- `config/experience.tsx`: work experience
- `config/skills.ts`: skill set shown in the "full arsenal" modal
- `components/Sections/FeaturedWorks/index.tsx`: featured projects (images in `public/works/`)

## Getting started

There's a `.nvmrc`; run `nvm use` if you have nvm installed.

```bash
yarn install
yarn dev
```

Then open http://localhost:3000/.
